# Laxman Singh Jadon — Professional Portfolio

Personal portfolio for **Laxman Singh Jadon**, HR Lead at IG Strategic Systems Pvt Ltd (IG Defence).

The site is designed as a digital extension of the professional CV, presenting the career journey, measurable impact, operating capabilities, education and certifications through an interactive interface.

## Highlights

- Fixed side navigation with scroll progress and active-section highlight (top bar + drawer on mobile)
- Interactive career journey with a responsibility growth chart and promotion ladder
- SVG infographics: compliance bars, workforce grid, span-of-ownership wheel, before/after operating model, delivery lifecycle
- Illustrated case studies: IG Defence Production & Manufacturing and Mahakumbh 2025 Tent City
- Quote bands between sections
- Education timeline, certification badges and Beyond Work
- Dark/light mode, scroll-reveal motion (respects reduced-motion), SEO metadata
- "Leave a note" form that opens the visitor's email app
- GitHub Pages deployment via GitHub Actions

## Editing content

All text, numbers, quotes and lists live in `src/data.js`. Illustrations are in `src/Illustrations.jsx`.

## CV PDF

The downloadable CV is `public/assets/Laxman_Singh_Jadon_CV.pdf`, generated by `scripts/build_cv.py` (needs `pip install reportlab`). Re-run it after editing the CV text, then commit the new PDF.

## Stack

- React 18
- Vite
- Tailwind CSS
- Lucide React
- GitHub Pages

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

```bash
npm run deploy
```

> Note: The public portfolio intentionally does not expose Aadhaar, PAN, driving licence or other confidential identity documents. A client-side PIN is not a security boundary for sensitive files.
